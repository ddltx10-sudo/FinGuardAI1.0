# FinGuardAI

## Описание проекта

FinGuardAI — программная система для автоматизированного анализа финансового рынка через Telegram-бота. Проект получает рыночные данные, рассчитывает технические показатели и представляет результаты пользователю в структурированном виде.

Проект разработан как прототип аналитического инструмента для хакатона и предназначен для демонстрации автоматизированной обработки рыночных данных.

## Проблема

Для анализа рынка пользователю необходимо одновременно отслеживать цену актива, объём торгов и несколько технических индикаторов. Ручной сбор и обработка этих данных занимает время и усложняет получение единой картины рынка.

FinGuardAI объединяет получение данных и их обработку в одном Telegram-интерфейсе.

## Цель проекта

Создать удобную систему автоматизированного анализа рыночных данных, которая позволяет получать основные технические показатели и сводную информацию о состоянии рынка в одном месте.

## Основные возможности

- получение актуальных рыночных данных;
- получение текущей цены актива;
- расчёт RSI;
- расчёт SMA;
- расчёт EMA;
- анализ объёма торгов;
- расчёт Anomaly Score;
- формирование сводного анализа;
- предоставление результатов через Telegram-бота.

## Принцип работы

1. Пользователь отправляет запрос Telegram-боту.
2. Система получает необходимые рыночные данные.
3. Данные проходят обработку.
4. Рассчитываются технические показатели.
5. Формируется итоговый аналитический результат.
6. Результат отправляется пользователю в Telegram.

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/Di-code-java/FinGuardAI.git
cd FinGuardAI
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Windows:

```bash
.venv\\Scripts\\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Настройка

Создайте файл `.env` в корневой директории проекта.

Пример необходимых переменных находится в `.env.example`.

Пример:

```env
BOT_TOKEN=ваш_telegram_токен
BINANCE_API_KEY=ваш_api_ключ
BINANCE_API_SECRET=ваш_api_secret
```

Реальные токены и ключи нельзя публиковать в GitHub.

## Запуск

После установки зависимостей и настройки `.env` запустите основной файл проекта:

```bash
python bot.py
```

Если в текущей версии проекта используется другой файл запуска, необходимо использовать соответствующую команду.

## Безопасность

Файл `.env`, API-ключи, Telegram Bot Token, пароли и другие секретные данные не должны попадать в публичный репозиторий. Для примера конфигурации используется `.env.example`.

## Anomaly Score

Anomaly Score используется для оценки отклонения текущих рыночных данных от поведения, определяемого алгоритмом проекта. В расчёте могут использоваться изменения цены, объём торгов и другие доступные параметры.

Точный алгоритм расчёта определяется реализацией проекта.

## Ограничения

FinGuardAI является инструментом обработки и анализа рыночных данных. Результаты системы не являются финансовой рекомендацией и не гарантируют прибыль. Решения о финансовых операциях пользователь принимает самостоятельно.
