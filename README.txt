FINGUARD AI
Система анализа финансового рынка через Telegram-бота

1. ОПИСАНИЕ ПРОЕКТА

FinGuardAI — программная система для автоматизированного анализа финансового рынка через Telegram-бота. Проект получает рыночные данные, рассчитывает технические показатели и представляет результаты пользователю в структурированном виде.

2. ПРОБЛЕМА

Для анализа рынка пользователю необходимо одновременно отслеживать цену актива, объём торгов и несколько технических индикаторов. Ручной сбор и обработка этих данных занимает время.

FinGuardAI объединяет получение данных и их обработку в одном Telegram-интерфейсе.

3. ЦЕЛЬ ПРОЕКТА

Создать удобную систему автоматизированного анализа рыночных данных, которая позволяет получать основные технические показатели и сводную информацию о состоянии рынка в одном месте.

4. ОСНОВНЫЕ ВОЗМОЖНОСТИ

- получение актуальных рыночных данных;
- текущая цена актива;
- RSI;
- SMA;
- EMA;
- объём торгов;
- Anomaly Score;
- сводный анализ;
- отображение результатов в Telegram.

5. ПРИНЦИП РАБОТЫ

1) Пользователь отправляет запрос Telegram-боту.
2) Система получает рыночные данные.
3) Данные обрабатываются.
4) Рассчитываются технические показатели.
5) Формируется аналитический результат.
6) Результат отправляется пользователю.

7. УСТАНОВКА

Клонировать репозиторий:

git clone https://github.com/Di-code-java/FinGuardAI.git
cd FinGuardAI

Создать виртуальное окружение:

python -m venv .venv

Windows:

.venv\Scripts\activate

Установить зависимости:

pip install -r requirements.txt

8. НАСТРОЙКА

Создайте файл .env в корневой директории проекта.

Пример переменных находится в .env.example.

BOT_TOKEN=ваш_telegram_токен
BINANCE_API_KEY=ваш_api_ключ
BINANCE_API_SECRET=ваш_api_secret

Реальные токены и API-ключи нельзя публиковать в GitHub.

9. ЗАПУСК

После установки зависимостей и настройки .env:

python bot.py

10. БЕЗОПАСНОСТЬ

Не загружайте в публичный репозиторий:
- файл .env;
- Telegram Bot Token;
- Binance API Key;
- Binance API Secret;
- пароли и другие секретные данные.

11. ANOMALY SCORE

Anomaly Score используется для оценки отклонения текущих рыночных данных от поведения, определяемого алгоритмом проекта. Точный алгоритм расчёта определяется реализацией проекта.

12. ОГРАНИЧЕНИЯ

FinGuardAI является инструментом обработки и анализа рыночных данных. Результаты системы не являются финансовой рекомендацией и не гарантируют прибыль.
